# NoteFlow

**NoteFlow** is a modern, premium Notes mobile application built with Expo and React Native.

Designed to make capturing ideas, organizing information, and managing personal and professional notes simple, secure, and enjoyable.

## Features

- Premium mobile-first interface
- Create, edit, and delete notes
- Rich-text note editing
- Organize notes by categories
- Add multiple tags to notes
- Search notes by title, content, and tags
- Mark notes as favorites
- Pin important notes
- Customize note colors
- Automatic note saving
- Local database storage
- Secure note storage architecture
- Dark mode support
- Smooth animations and transitions
- Responsive Android and iOS layouts

## Technology Stack

- Expo
- React Native
- TypeScript
- Expo Router
- React Native StyleSheet
- Expo SQLite
- AsyncStorage
- Expo SecureStore
- Expo Crypto
- React Native Pell Rich Editor
- React Native WebView
- React Native Reanimated
- Expo Haptics
- Expo Linear Gradient

## Installation

Clone the repository:

```bash
git clone https://github.com/LabibArefin123/note_flow_expo
```

Navigate into the project:

```bash
cd NoteFlow
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

## Development

Run on Android:

```bash
npx expo start --android
```

Run on iOS:

```bash
npx expo start --ios
```

Run Expo Doctor:

```bash
npx expo-doctor
```

## Project Structure

- `src/app/` - Application screens and navigation
- `src/components/` - Reusable UI components
- `src/constants/` - Application constants, colors, and categories
- `src/database/` - SQLite database configuration and queries
- `src/styles/` - Styling and design system
- `src/hooks/` - Custom React hooks
- `src/services/` - Note, category, and security services
- `src/types/` - TypeScript definitions
- `assets/` - Images, fonts, and icons
